# TailwindCSS UI Kit

> A reusable UI component kit built with TailwindCSS and React

## 📦 Installation

```bash
npm install
npm run dev
```

## 🚀 Initial Setup

- Clone the repository

- Install dependencies

- Run the project

🎨 Included Components

```jsx
Button
jsx
<Button variant="primary">Click me</Button>
<Button variant="secondary">Cancel</Button>
```
